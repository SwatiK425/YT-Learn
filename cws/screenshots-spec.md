# Praxis — CWS Screenshot Spec

CWS requires 1–5 screenshots, **1280x800 or 640x400** (use 1280x800).

## Capture method (2 options)

**Option A — DevTools (recommended, exact size):**
1. Open a YouTube video with the extension loaded (chrome://extensions → Developer mode → Load unpacked → `extension/`).
2. Click the Praxis button in the YouTube toolbar → exercise panel opens.
3. F12 → click the device toolbar icon (mobile/tablet toggle) → set viewport to **1280x800** → refresh so the panel re-renders at that size.
4. Screenshot via F12 → ⋮ menu → "Capture full size screenshot" (or Windows Snipping Tool).

**Option B — Resize after capture:**
Capture normally, then resize to exactly 1280x800 (any image editor). CWS crops to 640x400 in listings, so keep important content in the central band.

## The 5 shots

| # | What to show | Notes |
|---|---|---|
| 1 | YouTube video page with the Praxis button visible in the toolbar | Pick a video that teaches a process (tutorial/how-to). The RGB infinity-loop button should be clearly visible. |
| 2 | Exercise panel open: title + numbered steps | The generated exercise in the Praxis sidebar/overlay. |
| 3 | Exercise panel scrolled: done criteria + why it matters | Shows the concrete, measurable success criteria. |
| 4 | Feedback row (👍/👎) + "Mark done" | Shows the close-the-loop interaction. |
| 5 | Optional: settings (BYOK key entry) | Shows the "bring your own key" flow. Blur the key if one is present. |

## Rules
- No misleading content — the screenshots must show the real extension UI.
- Blur/crop any API keys, personal emails, or private video metadata you don't want public.
- Keep the RGB branding consistent — it's the visual identity.
